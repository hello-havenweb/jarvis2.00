# Changelog

## [1.0.0] - 2024-01-01

### Added
- Initial release of JARVIS personal AI assistant
- PySide6 dark futuristic GUI with reactor animation
- Text command mode (always available)
- Voice input via faster-whisper (optional)
- Local TTS via pyttsx3 (optional)
- Ollama local LLM integration
- Multilingual support with auto language detection
- PC control tools (open/close apps, system info, volume, etc.)
- File management (list, search, create, copy, move, rename, delete)
- Browser automation via Playwright
- Email support (IMAP/SMTP)
- WhatsApp Web automation (optional)
- HAVEN business data integration
- Batch file processing with state persistence
- SQLite memory and conversation storage
- Reminder system with scheduler
- Daily progress reports
- Permission system (SAFE/CONFIRM/DANGEROUS/BLOCKED)
- Audit logging
- Comprehensive diagnostics
- Automated installer and updater
