# JARVIS Quick Start

## 5-Minute Setup

1. **Install Python 3.11.x** → https://python.org → Check "Add to PATH"
2. **Install Ollama** → https://ollama.ai
3. **Pull a model** → Open terminal: `ollama pull llama3`
4. **Run installer** → Double-click `install.bat`
5. **Start JARVIS** → Double-click `run_jarvis.bat`

## First Commands to Try

- Type: `hello`
- Type: `open notepad`
- Type: `show system status`
- Type: `take screenshot`
- Type: `what time is it`

## No Microphone? No Problem!

Text mode always works. Voice is optional.

## Need Help?

Run `diagnose.bat` to check what's working.
